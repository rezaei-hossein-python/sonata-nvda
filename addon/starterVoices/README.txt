NVDA Piper Driver offline starter pack

The voice model files in this directory are copied into the active NVDA
configuration's sonata/voices/piper directory during add-on installation.
Existing voice directories are never merged with or overwritten.

The storage and runtime names remain "sonata" for compatibility with existing
Sonata Neural Voices installations and previously downloaded voices.

Each voice directory retains the Piper MODEL_CARD supplied with the model.
See LICENSES.md and manifest.json for source, license, size, and hash details.
