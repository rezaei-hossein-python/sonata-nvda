# Offline starter voice licenses

The starter models are separate data works obtained from the Piper v1.0.0
catalog. Each model was trained from scratch, avoiding an unclear base-model
license chain. Original `MODEL_CARD` files are retained beside every model.

| Voice | Language | Dataset/model terms | Source |
| --- | --- | --- | --- |
| en_US-ljspeech-medium | English (US) | Public domain | https://keithito.com/LJ-Speech-Dataset/ |
| fr_FR-mls-medium | French (France) | CC BY 4.0 | http://openslr.org/94/ |
| de_DE-mls-medium | German (Germany) | CC BY 4.0 | http://openslr.org/94/ |
| es_ES-carlfm-x_low | Spanish (Spain) | Public domain | https://github.com/carlfm01/my-speech-datasets |

Catalog/model source:
https://huggingface.co/rhasspy/piper-voices/tree/v1.0.0
