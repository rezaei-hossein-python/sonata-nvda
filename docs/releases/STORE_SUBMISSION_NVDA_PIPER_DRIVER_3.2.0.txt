Submission notes:

NVDA Piper Driver is a maintained fork of Sonata Neural Voices, originally
developed by Musharraf Omer. A distinct add-on ID and display name are used to
avoid conflict with the original Sonata identity. Upstream attribution and GPL
licensing are preserved. This release provides NVDA 2026 AMD64 / CPython 3.13
compatibility, four bundled offline starter voices, and an accessible Voice
Manager for additional Piper voices. Existing Sonata voice libraries remain in
the same local directory and are preserved during migration.

This packet is for manual submission by Hosein Rezaii. It does not claim
approval or endorsement by Musharraf Omer or NV Access.
