# NVDA Piper Driver 3.2.0

NVDA Piper Driver 3.2.0 establishes a distinct maintained-fork identity for
the NVDA 2026 AMD64 adaptation of Sonata Neural Voices. Sonata Neural Voices
and the underlying Sonata engine were originally developed by Musharraf Omer;
this is not a from-scratch speech-synthesis implementation.

## Highlights

- New Store-safe add-on ID `nvdaPiperDriver` and display name **NVDA Piper
  Driver**.
- Maintained by Hosein Rezaii for NVDA 2026.1.1 on AMD64 Windows.
- Native CPython 3.13 dependencies with no x86 native modules.
- Proven Sonata synthesis runtime retained without semantic changes.
- Invisible, lifecycle-managed `sonata-grpc.exe` backend.
- Four bundled offline starter voices: English, French, German and Spanish.
- Accessible Voice Manager with the multilingual Piper catalog, previews,
  validated online installation and local archive installation.
- Standard and fast/RT variant support where a real catalog variant exists.
- Installed voices continue working offline.
- Existing voice library remains at `<NVDA configPath>\sonata\voices\piper`.
- Clean synth switching, backend restart and NVDA shutdown behavior.
- Original Sonata attribution, GPL licensing, third-party notices and voice
  model cards preserved.

## Migration from Sonata Neural Voices 3.1.1

The new add-on ID means NVDA may initially display both add-ons. Install and
verify NVDA Piper Driver 3.2.0 first. Both releases use the same local voice
library, so existing downloaded voices do not need to be copied or converted.

After confirming NVDA Piper Driver speaks correctly:

1. Remove Sonata Neural Voices 3.1.1 through NVDA's Add-on Manager.
2. Restart NVDA.
3. Select **NVDA Piper Driver** in speech settings if necessary.
4. Confirm the existing voices are still listed.

Removing the old add-on does not remove the shared voice directory. The
internal synth driver identifier remains `sonata_neural_voices` to preserve
NVDA settings compatibility; its displayed name is **NVDA Piper Driver**.
