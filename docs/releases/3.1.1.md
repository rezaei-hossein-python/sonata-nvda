# Sonata Neural Voices 3.1.1

Sonata Neural Voices 3.1.1 is a maintained NVDA 2026 AMD64 adaptation of the
original Sonata NVDA add-on by Musharraf Omer.

## Highlights

- Supports stable NVDA 2026.1.1 on Windows AMD64.
- Updates native Python dependencies for NVDA's CPython 3.13 runtime.
- Starts the Sonata backend invisibly and manages it through NVDA's synthesizer
  lifecycle, including clean switching and shutdown.
- Includes offline English, French, German, and Spanish starter voices.
- Keeps the online Sonata Voice Manager available for additional languages and
  voices.
- Repairs online MP3 voice previews and reports download, decode, and playback
  failures accessibly.
- Supports multilingual Piper voices and standard/fast variants where offered
  by the catalog.
- Updates maintainer and support information for this fork.

Normal synthesis is offline after a voice has been installed. Internet access
is required only for catalog loading, previews, and optional voice downloads.

The original Sonata project and NVDA add-on were created by Musharraf Omer. This
release preserves his attribution and the upstream GPL history. The NVDA 2026
AMD64 / CPython 3.13 fork is maintained by Hosein Rezaii
<rezaii.hosein@gmail.com>.
