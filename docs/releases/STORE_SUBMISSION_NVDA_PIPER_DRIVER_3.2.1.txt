Submission notes:

NVDA Piper Driver is a maintained fork of Sonata Neural Voices, originally
developed by Musharraf Omer. A distinct add-on ID and display name avoid a
conflict with the original Sonata identity. Upstream attribution and GPL
licensing are preserved. Version 3.2.1 schedules Sonata Neural Voices 3.1.1 for
removal through NVDA's supported add-on lifecycle while preserving downloaded
voices and the shared local voice directory. Bundled starters are deployed only
on genuinely fresh installations; migration and same-ID updates make no changes
to an established voice tree. It provides NVDA 2026 AMD64 / CPython 3.13
compatibility, four bundled offline starter voices for new installations, and
an accessible Voice Manager for additional Piper voices.

This packet is for manual submission by Hosein Rezaii. It does not claim
approval or endorsement by Musharraf Omer or NV Access.
