# NVDA Piper Driver 3.2.1

NVDA Piper Driver 3.2.1 is a focused migration patch for the maintained NVDA
2026 AMD64 adaptation of Sonata Neural Voices. Sonata Neural Voices and the
underlying Sonata engine were originally developed by Musharraf Omer; this
release preserves that attribution and the upstream GPL history.

## Changes

- During installation, detects the add-on ID `sonata_neural_voices` at exact
  version `3.1.1` and schedules it for removal with NVDA's supported
  `Addon.requestRemove()` lifecycle.
- Repeated installation is idempotent when the legacy add-on is already pending
  removal.
- Add-on enumeration or removal-state failures are logged without aborting NVDA
  Piper Driver installation.
- Other Sonata Neural Voices versions are deliberately left installed for
  manual review.
- The shared `<NVDA configPath>\sonata\voices\piper` directory is never deleted,
  moved, renamed or rewritten by the migration.
- Bundled starter voices are deployed only on a genuinely fresh installation.
  Migration from Sonata Neural Voices and updates from NVDA Piper Driver 3.2.0
  skip starter deployment, so an established voice tree is not changed.

The internal synthesizer module remains `sonata_neural_voices`, and the global
plugin remains `sonata_tts_global_plugin`. Synthesis, models, phonemization,
normalization, the gRPC backend, Voice Manager and user preferences are
unchanged from the validated 3.2.0 release.

## Migration

1. Install `nvdaPiperDriver-3.2.1.nvda-addon` through NVDA.
2. Restart NVDA when prompted. Sonata Neural Voices 3.1.1 will be removed as
   part of NVDA's normal pending-removal lifecycle.
3. Select **NVDA Piper Driver** if necessary. Existing downloaded voices remain
   available from the unchanged shared voice library.

The four bundled starters are installed automatically for new users who have
neither Sonata Neural Voices nor NVDA Piper Driver installed. They are not added
to an existing voice library during migration or update.
